# World of Games

Console game app in Python with three games: Memory Game, Guess Game and Currency Roulette.
 Part 1 of a DevOps project.

## Run
 pip install -r requirements.txt
 python MainGame.py

## Games
 - Memory Game: remember a sequence shown for 0.7 seconds
 - Guess Game: guess the computer's secret number
 - Currency Roulette: estimate the ILS value of a random USD amount (live rate from open.er-api.com)

Difficulty goes from 1 to 5.
